# Demo product image slots

The public catalog uses optimized, non-branded files named `product-01.webp`
through `product-64.webp`, plus matching `product-01-tryon.webp` through
`product-64-tryon.webp` detail views. Original PNG masters remain local source
assets. See `docs/demo-product-imagery.md` for required safety and recommended
export specifications.

Missing delivery files render as stable 4:5 placeholders.
